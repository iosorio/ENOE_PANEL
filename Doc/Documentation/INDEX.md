# Documentation Index

This index lists consolidated ENOE documentation (questionnaires, crosswalks, and reference notes). Files are grouped into `common` (shared across years) and `by-year` (year-specific notes or instruments).

## How to use this index
- Start with `common/` for crosswalks and global reference files.
- Use `by-year/YYYY/` for year-specific survey notes or instruments.

## Common
- `common/Industry_Occupation_ReadMe.txt` - Industry/occupation coding overview and mappings.
- `common/Industry_Occupation_ReadMe_e4a0c9dc.txt` - Alternate industry/occupation notes (variant content).
- `common/SCIAN_02_ISIC_3.1.xlsx` - SCIAN 2002 to ISIC Rev.3.1 crosswalk.
- `common/SCIAN_07_ISIC_4.xlsx` - SCIAN 2007 to ISIC Rev.4 crosswalk.
- `common/SCIAN_07_ISIC_4_f79990c9.xlsx` - SCIAN 2007 to ISIC Rev.4 crosswalk (alternate file).
- `common/SCIAN_13_ISIC_4.xlsx` - SCIAN 2013 to ISIC Rev.4 crosswalk.
- `common/SCIAN_18_ISIC_4.xlsx` - SCIAN 2018 to ISIC Rev.4 crosswalk.
- `common/Where is this data from - ReadMe.txt` - Data provenance notes for ENOE inputs.
- `common/c_amp_v1._05-06.pdf` - ENOE questionnaire annex (ampliado) for 2005–2006.
- `common/c_amp_v3-10-12.pdf` - ENOE questionnaire annex (ampliado) for 2010–2012.
- `common/c_amp_v4-13-15.pdf` - ENOE questionnaire annex (ampliado) for 2013–2015.
- `common/tablas_comparativas.xlsx` - Comparative classification tables across coding versions.
